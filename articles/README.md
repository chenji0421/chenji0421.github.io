# 文章写作说明

这里是这个网站「真实内容」的来源。网站本身**不会自动生成文章**，
所有文章都由你自己写、自己登记，才会显示在网站上。

## 如何写一篇文章

1. **复制模板**：复制 [`template.md`](template.md) 到本目录，比如 `my-first-post.md`。
2. **填写文章头信息**（文件开头的 `---` 部分）：

   ```yaml
   title: 文章标题
   date: 2026-08-09
   category: 学习笔记        # 学习笔记 / 项目记录 / 技术复盘 / 生活记录
   tags:
     - Python
     - 前端
   summary: 一句话摘要
   ```

3. **写正文**：用 Markdown 写内容。网站支持：
   - `#` / `##` / `###` 标题
   - 普通段落
   - `-` 列表
   - ` ``` ` 代码块（会按代码块显示）
   - `**加粗**`
   - 链接 `[文字](地址)`、行内代码 `` `代码` ``

4. **登记到网站**：打开 `js/content.js`，在 `siteContent.articles` 数组里加一个对象：

   ```js
   {
     title: "我的第一篇文章",
     date: "2026-08-09",
     category: "学习笔记",
     tags: ["Python", "前端"],
     summary: "这里是摘要，会显示在文章卡片上",
     file: "articles/my-first-post.md"
   }
   ```

   `file` 字段必须指向真实的 Markdown 文件路径。

5. **提交推送**：

   ```bash
   git add articles/ js/content.js
   git commit -m "feat: 添加新文章：我的第一篇文章"
   git push origin main
   ```

   推送后 GitHub Pages 会自动更新，文章卡片就会出现在「文章」页。

## 写文章的原则

- **不写假阅读量**：文章数据里没有 views / readTime 字段，不要自己编。
- **不写假浏览量**：浏览量只有真实部署后才能统计，现在放 0 或留空就好。
- **只写自己写过的**：不要为了让网站看起来丰富而编造没写过的东西。
- **每篇都要有正文文件**：只在 `js/content.js` 登记、但 `articles/` 下没有对应
  Markdown 文件的文章，点开会提示「文章文件不存在」。

## 网站会怎么显示

- 文章卡片：标题 + 分类 + 日期 + 摘要 + 标签
- 点击卡片：打开文章详情，网站会 `fetch` 你登记的 Markdown 文件并渲染成页面
- 搜索 / 标签 / 分类 / 月份筛选：全部根据你登记的文章**自动计算**，不需要手动维护

## 目录结构

```
articles/
├── README.md      ← 本文件
└── template.md    ← 文章模板，写新文章时复制它
```
