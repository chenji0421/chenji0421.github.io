# 学习笔记（新手向）

> 这些是作者（非科班、正在自学）的笔记。不一定是最优解，但保证是「踩过坑、能跑通」的记录。
> 建议配合代码一起看，改一行 → 刷新 → 看效果。

## 1. 静态网页是怎么上线的？

- 你写了一个 `index.html`，里面有 `<div>你好</div>`。
- 浏览器访问时，服务器（这里就是 GitHub Pages）**原封不动**把文件发给你。
- 所以：静态页 = 「服务器只是快递员，不拆包裹、不算数学」。

## 2. 为什么会有「构建」这一步？

- React 的代码是 `.jsx`，浏览器**不认**。
- 需要工具（Vite）把 `.jsx` 翻译成浏览器认识的普通 `.js` / `.css`。
- 这个过程叫 **build / 构建**，产物放在 `dist/` 文件夹。
- 你现在本地 `npm run dev`，Vite 在你打字的同时悄悄做这件事，所以叫「热更新」。

## 3. 前端和后端到底怎么聊天？

- 前端在浏览器里，后端在服务器上，两边靠 **HTTP 请求** 对话。
- 后端返回的是**数据**（通常是 JSON），不是网页。
- 例子：`GET /api/posts` → 返回 `[{"title": "...", "tags": [...]}, ...]`。
- 前端拿到数据，渲染成卡片。这个「拿数据」的动作，浏览器里叫 **fetch**。

## 4. FastAPI 帮我避开的坑

- **启动要在 backend 目录下**：`uvicorn app.main:app --reload`，
  `app.main:app` 意思是「app 包里的 main.py 文件里的 app 变量」。
- **改了代码要重启**：加 `--reload` 参数能自动重启，新手必加。
- **`/docs` 是免费的**：FastAPI 根据你的代码自动生成接口文档，还能直接点「Try it out」测试。
- **CORS**：前端在 5173、后端在 8000，跨端口请求会被浏览器拦，
  所以 main.py 里加了 `CORSMiddleware`。这是新手最容易卡住的地方。

## 5. 关于 `.env`

- 代码里不能写密码、Token —— 一旦推到 GitHub 就全世界都能看到。
- 正确姿势：把敏感值写进 `.env`（已被 `.gitignore` 忽略），
  代码里用 `os.getenv(...)` 或 pydantic-settings 读取。
- `.env.example` 是「模板」，只写变量名不写真值，可以放心提交。

## 6. 怎么看懂报错

- **前端报错**：打开浏览器 F12 → Console，红色的就是错误，点开看第几行。
- **后端报错**：终端里红色 Traceback，从下往上看（最后一行是最外层原因）。
- **GitHub 报错**：Actions 页面点进失败的 job，红色的 step 就是出事的地方。

## 7. 一个「今天就能试」的小实验

```bash
# 1. 起后端
cd backend && pip install -r requirements.txt && uvicorn app.main:app --reload

# 2. 另开一个终端，用浏览器打开下面的地址
#    http://127.0.0.1:8000/api/posts
```

看到一坨 JSON 就成功了。然后试着改 `database_seed.py` 里的文章标题，刷新接口，内容变了 → 你就懂「数据存在后端」了。
