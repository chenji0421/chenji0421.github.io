本站是怎么运作的

这是一个 GitHub Pages 静态网站，没有后端服务器、没有数据库、也没有登录系统。 访客访问网站时只能看到公开内容；所有内容都由站长通过 GitHub 仓库 维护， 修改文件并推送后，网站会自动更新。

📝

📦

登记在 js/content.js 或 data/projects.json

🌍

公开计划

写在 data/plans.json，所有人访问网站都能看到

🔒

本地计划

只保存在你自己的浏览器 localStorage 里，不会上传、别人看不到

打开 GitHub 仓库 查看写作说明 查看内容维护指南

🔄 数据是怎么更新的

  1. 你在 GitHub 仓库里修改 articles/、js/content.js、data/plans.json
  2. 推送到 main 分支（git push）
  3. GitHub Pages 自动重新构建，几十秒后访客看到最新公开内容

ℹ️ 本站没有任何登录功能。如果你以后想要「评论、账号、后台管理」，需要先学习后端和数据库，再接入真实服务。
