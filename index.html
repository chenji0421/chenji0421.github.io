    提示：点击「新窗口打开」可全屏试玩（当前暂无真实游戏地址）

    游戏规则

    双方各抽一张卡比大小：点数高者胜，同点则平局。三局两胜制，先赢两局的一方获胜。规则简单，适合练手。

    🛠️

    技术实现

    计划使用纯 HTML5 + CSS + JavaScript 实现，不依赖任何框架。洗牌算法 + 简单的比对逻辑，全部在浏览器本地运行。
